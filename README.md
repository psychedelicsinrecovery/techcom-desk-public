# 💻 TechCom: PIR®'s Tech Committee helpdesk

> 🌐 **Portal:** https://psychedelicsinrecovery.github.io/techcom-desk-public/ · 💬 **In Discord:** type `/techcom` · 📨 **No Discord?** [Web helpdesk](https://psychedelicsinrecovery.github.io/alex-desk-public/portal.html)

**Website, email, forms, Zoom and calendar.** TechCom is where members of **Psychedelics In Recovery™ (PIR®)** ask the Tech Committee for help. Every
request becomes a private ticket that a trusted servant claims, works on and resolves, so nothing gets lost in a
group chat.

## 🧭 What this desk handles
- Problems with the websites (psychedelicsinrecovery.org and the service site)
- Email, forms, Zoom and calendar issues
- Privacy and data requests (with the Privacy Policy & Data Stewardship subcommittee)

## 🎫 How a ticket works
1. **Open it:** type `/techcom` anywhere in [PIR®'s Discord](https://discord.gg/MyprTq8w95) and fill in the short form, or use the
   [web helpdesk](https://psychedelicsinrecovery.github.io/alex-desk-public/portal.html) with a one-time email link (no password, no account).
2. **A private thread opens** that only you and the Tech Committee can see. Your ticket gets an ID like `TECH-12`.
3. **Someone claims it** and you'll see its status move: 🆕 new → 🙋 claimed → 🛠️ in progress → ✅ resolved.
4. **Resolved tickets are archived.** Still need help? Tap **Reopen** in the thread.
5. **Check status any time** with `/ticket TECH-12` in Discord, or under *My tickets* on the web desk.

## 🔒 Privacy
- Tickets are tracked in a **private** repository. Requesters appear only as a scrambled tag, never a Discord ID or an email address.
- A.L.E.X. (the helper that runs the desks) only sees what you type into its forms and stores no chat history.
- Please don't share passwords or sensitive personal details in a ticket.
- Full notice: [Privacy](https://psychedelicsinrecovery.github.io/alex-desk-public/privacy.html) · [Terms](https://psychedelicsinrecovery.github.io/alex-desk-public/terms.html)

## 🪞 Public mirror
This repository is a **read-only public mirror** that publishes the desk's portal on GitHub Pages. It's generated
from PIR®'s private desk repository by the Tech Committee's build (`alex-desk/site/build.py`) and pushed here
automatically by the *Public Mirror Bot*, so changes are made at the source and pull requests here can't be merged.
Ideas or corrections? Open a ticket with `/techcom`.
